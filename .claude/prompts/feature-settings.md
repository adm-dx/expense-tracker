# Новая функциональность
Модуль настроек пользователя, бэкенд + фронтэнд

## Контекст:
Проект: Nest.js + Next + PostgreSQL + Prisma. Что уже есть: API авторизации, регистрации пользователя, 
API категорий, фронтэнд авторизации и регистрации пользователя, главная страница, категории. Авторизация JWT токен с refresh. Есть модули User и
Categories

## Задача:
Создать модуль пользовательских настроек:
1) тема приложения - берем из дизайн системы
2) местоположение
3) валюта по умолчанию
4) смена пароля
5) сброс настроек на настройки по умолчанию

## Модель данных:
на твое усмотрение, все настройки должны сохраняться для каждого пользователя отдельно со стороны БД 
можно сделать так: колонка пользователь - пользователь, колонка настройки - json с настройками
используй best practice

## Контроллеры:
стандартный CRUD для чтения, редактирования, сохранения настроек

## Паттерны:
Используй apps/api/src/modules/categories как образец структуры для модулей backend

## Ограничения:
- Не добавлять зависимости если это не просят в задаче
- Использовать class-validator для dto
- После реализации собирай проект
- План реализации пиши в папку .claude/plans
